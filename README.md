# Кафе «Ланч» — демо-сайт для портфолио

Одностраничный сайт кафе быстрого питания и кофейни. **Заведение вымышленное**: название, логотип, адрес, телефон, цены и отзывы придуманы, фотографии намеренно размыты, а кнопки заказа и внешние ссылки работают в демо-режиме — по клику всплывает чек-уведомление о том, что сделал бы рабочий сайт (для WhatsApp/Telegram — с готовым текстом заказа).

Статичный сайт без сборки: `index.html` + `css/styles.css` + `js/main.js` + `img/demo/` + `fonts/`.

## Что умеет

- **Чек, который собирает заказ.** «+» у любого блюда печатает строку в чеке (состояние в `localStorage`), варианты объёма и размера, количество, итог. Чек превращается в готовое сообщение для мессенджера.
- **Десктоп:** чек висит справа рядом с меню, вокруг — фото-отпечатки, которые можно потаскать мышью.
- **Телефон и планшет:** нижняя панель «Звонок · WhatsApp · Чек», чек в шторке со свайпом вниз, липкая строка категорий меню, карточки «актуального» с автопролистыванием.
- **Статус «открыто / закрыто»** по московскому времени (08:00–23:00).
- Нарисованная схема проезда, доступность с клавиатуры, `prefers-reduced-motion`.

## Запуск локально

```bash
python -m http.server 8407
```

и открыть http://localhost:8407/.

## Меню

Меню генерируется из списка в [tools/build_menu.py](tools/build_menu.py). После правки:

```bash
python tools/build_menu.py
```

Скрипт перезапишет четыре блока в `index.html`: полное меню, «Содержание», чипы категорий и хиты в чеке. Хиты на табло размечены прямо в `index.html`.
